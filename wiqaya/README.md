# Wiqaya / وقاية

Responsive, buildless PWA design prototype. Serve dist over localhost or HTTPS.

Includes family hub, consent, profile builder, sample label comparison, simulated parent approvals, safe-list filtering and recipe removal, bilingual headings/RTL, dining card, child view and emergency dialer/SMS composition. Profile changes remain in session memory. Offline app shell uses a service worker.

Not a medical device. OCR, barcode lookup, AI, encrypted QR invitations, remote sync, verified legal compliance, and scheduled reminders are not implemented. Sample verdicts are not computed from uploaded photos. No prescriptions or doses are invented.

Run locally: python3 -m http.server 4173 --directory dist
